# Codeforces Contests and Problem Solutions

Solutions to Codeforces contests and practice problems.

## Layout

`Contests/` is grouped by round type:

- **Codeforces Round** — main rated rounds
- **Educational Codeforces Round** — extended educational rounds
- **Codeforces Alpha Round** — early/alpha rated rounds
- **Hello 2024** — themed round

Each contest directory contains one file per problem (A, B, C, …) with the solution.

## Languages

Primarily C++ with some Python.
